# Oh Story Xuanhuan（独立版开发区）

目标：保留原版 Oh Story，独立迭代 **xuanhuan-outline**（细纲）与 **xuanhuan-write**（正文），聚焦番茄男频玄幻长篇。

## 当前状态
- Alpha：已创建两份独立 Skill 入口与玄幻写作规则。
- 细纲沿用 Oh Story 的 9 个核心字段、四个必备小节、五段式内容与四列情节点表。
- 正文保持原始工程路径；**当前写作 Skill 在安全追踪提交器未完成独立封装前，不可自动声称整章已提交。**
- 原版保持不动；本目录不参与现有 `story-setup` 发布清单。

## 使用与边界
- 规划：`xuanhuan-outline` 只创建或修改点名章的细纲。
- 正文：`xuanhuan-write` 仅写指定章节正文，检查后通过 Oh Story 正规追踪提交流程登记。
- **禁止直接编辑** `追踪/_tracking-state.json` 和派生的 `追踪/上下文.md`、`伏笔.md`、`角色状态/`、`时间线/`。
- 同一本书只允许串行章级提交；状态不一致必须停下处理。

## 路线
1. 锁定兼容细纲输出，完成独立 outline 的契约回归。
2. 将可独立安装的必要运行时与 write Skill 打包，不依赖原版变化的内部路径。
3. 用冻结样例检查旧书新 Skill、原版互操作；验证 Codex 与 Claude Code 的发现和调用。
4. 迁出到单独仓库；两个 Skill 独立版本与发布。

开发期不得把 Alpha 当作已完成的独立运行时发布。
