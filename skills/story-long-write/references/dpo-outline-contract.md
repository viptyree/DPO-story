# DPO 专用章节细纲 v2（唯一权威）
本分支废弃原版九字段和五段式细纲。Codex 负责生成；claudeqwen 只读取并写正文。
存储路径不变：`大纲/细纲_第NNN章.md`；单元仍关联现有卷纲，追踪仍采用原版事务。

## 格式
```md
# 第21章：标题

## 章节控制
- 所属卷：第一卷
- 剧情单元：L1-03
- 目标字数：2500
- 字数口径：visible_chars_v1
- 视角：第三人称紧贴主角
- 章节目标：……
- 目标情绪：……
- 章尾停笔点：……

## 〖人物状态〗
- 主角：境界、位置、目的、伤势和认知
- 其他出场人物：位置、立场、当前行动

## 〖前情〗
- 当前局势：……
- 必须承接：……

## 〖事件骨架〗
1. 可执行、可观察的动作与因果。
2. 对手的具体反应。
3. 主角的选择及其代价。
4. 允许兑现的阶段结果。

## 〖写作要求〗
- 叙事风格：……
- 禁止提前释放：……
- 结尾：……

## 长篇追踪约束
- 必须沿用的事实：……
- 允许发生的状态变化：……
- 本章禁止变动的设定：……
- 下一章承接的事实：……
```
四个 `〖〗` 标题为写手专用章节输入；章节控制和追踪约束是 Codex/编译器使用的工程字段。
`〖人物状态〗` 与 `〖前情〗` 是**该章规划时的事实快照**；正文写前以权威追踪的实际状态覆盖过时信息，绝不反向篡改已提交追踪。
严禁将完整卷纲、工程约束、模型调用指令和未授权后续剧透原样塞进写手 Prompt。
需迁移旧细纲时，先备份后转换，无法推导的字段标记待作者裁决，不凭空杜撰。
