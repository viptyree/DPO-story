# DPO 专用细纲规划（Codex 阶段）

本分支原版九字段与五段式已废弃。新章唯一合法格式：`references/dpo-outline-contract.md`。

1. 依据现有世界观、人物卡、当前卷纲剧情单元、伏笔与读者已知事实生成细纲；按作者指定章节范围，不自动扩写。
2. 每章必须有可执行的 `〖事件骨架〗`（动作、反应、取舍、结果），不能只写「制造爽点」「留下悬念」。
3. 细纲正文中直接包含 `〖人物状态〗`、`〖前情〗`、`〖事件骨架〗`、`〖写作要求〗`；另有章节控制与长篇追踪约束，不另建场景卡。
4. `目标字数` 是全章目标；不为凑长度增补未经授权的剧情事件；默认整章一次生成。章尾停笔点必须具体可核。
5. 仍保留卷纲的单元 ID、阶段信息边界，必要时使用 `outline_view.py --unit` 定点提取，禁止整卷素材无差别下发。
6. 作者明确的定设定与规划确认点保持不变，规划完成即停，不擅自转入正文。
7. 落盘到 `大纲/细纲_第NNN章.md` 后：`node {skill根}/scripts/check-outline-contract.js --json --project {书目录} --chapter {N}`，不通过则仅修复指出的字段。
8. 既有细纲必须经人工校核迁移后才写正文，不允许旧九字段静默通过新版检查器。

**DPO写作模型不负责创建细纲。** Codex 负责所有规划、文件写入与检查。
