# Phase 0 选源与体检：拆文库输入契约

本 skill 只读拆文库，不拆书。拆文库由其他模型产出，目录形如 `{拆文库根}/<对标书名>/`。

## 必备文件（缺一即 missing_source）

| 文件 | 用途 | 缺了影响 |
| --- | --- | --- |
| `剧情/节奏.md` | EV 事件双时间线、循环单元、爽点/触动点、跨章伏笔 | Phase 2 爽点定位、章尾钩子 |
| `剧情/情绪模块.md` | EM-001.. 模块卡（可替换项/不可照搬/失效情形） | Phase 1 功能位保留、Phase 2 章节功能位 |
| `章节/第N章_摘要.md`（N=1..范围上限） | 每章 P1..Pn 情节点（类型/基调/涉及/地点/物品/时间） | Phase 2 情节点级迁移的唯一依据 |
| `文风.md` | 语感、对话技法、情绪交替、原文锚点、不可模仿 | Phase 1 点睛句/文风指令 |
| `设定/世界观/金手指.md` | 原书金手指规则（获取/升级/代价） | Phase 1 金手指映射 |
| `角色/<主角>.md` | 主角卡（archetype/别名/关键情节/变化/证据） | Phase 1 名词映射（主角） |

## 可选文件（有则增强，无则降级）

- `章节/第N章_深度拆解.md`：场景级拆解，用于第1章爆点位置精确定位。
- `设定/世界观/力量体系.md`：境界/战力映射，写入细纲 `长篇追踪约束`。
- `设定/世界观/背景设定.md`：世界名词映射来源。
- `角色/角色关系.md`：配角映射与立场。
- `角色/<配角>.md`：核心配角卡，映射更稳。

## 章节摘要格式约定（迁移输入）

每章 `第N章_摘要.md` 必须含 P 情节点清单，每点一行，含：类型、基调、涉及人物、地点、物品、时间。情节点数量**逐章不同**（如第1章=5 点，第14章=10 点），迁移时以该章实际点数为准，`换皮对照` 段记录实际点数。

## 体检流程

1. 定位拆文库根（运行时传入；默认 `D:\劳动仲裁\novel\yaomo\拆文库\`），列出其下对标书目录供选择。
2. 按上表逐项检查范围（默认前15章）内的文件是否存在、章节摘要是否齐全。
3. 输出 `missing_source` 报告：缺什么、影响哪个阶段、建议（补拆 or 降级继续）。
4. 缺必备项且作者选择降级：记录降级项（如缺力量体系则细纲 `长篇追踪约束` 少一条），继续。
5. 确认迁移范围（默认前15章），章号与原书一一对应。
