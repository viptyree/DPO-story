# 换皮细纲模板（与 dpo-outline-contract.md 格式一致 + 换皮对照段）

本模板与 `C:\Users\Tyree\.claude\skills\story-long-write\references\dpo-outline-contract.md` 的四段式逐段一致。唯一新增段 `## 换皮对照` 放在 `长篇追踪约束` 之后，是额外工程段；`build_dpo_prompt.py` 只取固定段名，该段不会进写手 Prompt，正文管线零改动。

## 模板

```md
# 第N章：{新书章名}

## 章节控制
- 所属卷：{卷名或「第一卷」}
- 剧情单元：GO-{N}
- 字数目标：{映射表统一值，默认2500}
- 字数口径：visible_chars_v1
- 视角：{第三人称紧贴主角 等}
- 章节目标：{本章要推进的剧情，一句}
- 目标情绪：{本章主导情绪}
- 章尾停笔点：{具体可核的结尾动作/状态，对齐原书钩子类型}

## 〖人物状态〗
- 主角：{境界、位置、目的、伤势和认知，用新书名词}
- 其他出场人物：{位置、立场、当前行动，用新书名词}

## 〖前情〗
- 当前局势：{开场前局势，用新书名词}
- 必须承接：{上一章遗留、必须推进的事实}

## 〖事件骨架〗
1. {P1：可执行、可观察的动作与因果，新书名词}
2. {P2：对手的具体反应，新书名词}
3. {P3：主角的选择及其代价，新书名词}
4. {P4：允许兑现的阶段结果，新书名词}
5. {P5：…（情节点数=原书该章实际P点数，逐章不同）}

## 〖写作要求〗
- 叙事风格：{映射表第5区块的文风指令，3-5条}
- 禁止提前释放：{本章不可提前揭示的信息/底牌}
- 结尾：{章尾停笔点的写法要求，对齐原书钩子}

## 长篇追踪约束
- 必须沿用的事实：{跨章不变的事实，用新书名词}
- 允许发生的状态变化：{本章内允许改变的状态}
- 本章禁止变动的设定：{本章不可改的设定/金手指规则}
- 下一章承接的事实：{本章末尾留给下一章的事实}

## 换皮对照
- 对标章节：原书第{N}章
- 原书情节点数：{原书该章实际P点数}
- 情节点对照：
  - P1：原书{一句话摘要} → 新书{一句话摘要}
  - P2：原书{一句话摘要} → 新书{一句话摘要}
  - …（逐点，点数=原书该章P点数）
- 功能位/EM引用：{本章生效的EM编号+模块名}
- 爽点位置：{原书该章爽点在第几个情节点，新书对齐位置}
- 禁用原书名词：{本章涉及的、不得泄漏进四段式的原书人名/地名/物品/组织}
```

## 格式一致性规则

1. 四段式 `〖人物状态〗〖前情〗〖事件骨架〗〖写作要求〗` 的段名、字段名、字段顺序与 `dpo-outline-contract.md` 逐字一致。
2. `## 章节控制` 的八个字段（所属卷/剧情单元/字数目标/字数口径/视角/章节目标/目标情绪/章尾停笔点）逐字一致。
3. `## 长篇追踪约束` 的四个字段（必须沿用的事实/允许发生的状态变化/本章禁止变动的设定/下一章承接的事实）逐字一致。
4. `## 换皮对照` 是唯一新增段，放在最后；写手编译器不读取，校验器额外校验。
5. 四段式正文中只出现新书名词；原书名词只允许出现在 `## 换皮对照` 段。

## 校验

- 主校验：`node "C:\Users\Tyree\.claude\skills\story-long-write\scripts\check-outline-contract.js" --json --project "{书目录}" --chapter {N}`（DPO格式，额外 `##` 段被忽略）。
- 换皮校验：`node "{本skill根}/scripts/check-go-outline.js" --project "{书目录}" --chapter {N}`（对标章节存在、情节点数与原书一致、禁用原书名词未泄漏进四段式）。
