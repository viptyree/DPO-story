# Phase 1 换皮映射表协议

输出文件：本书目录 `换皮/映射表.md`。作者确认并锁定后才进入 Phase 2。

## 目标

把原书的全部可识别素材（人名/地名/金手指/句式/口吻）换成新书等价素材，但**功能位、爽点位置、情绪链**保持不变。映射表是 Phase 2 逐章换名词的唯一依据，细纲里不许出现映射表之外的新名词。

## 映射表必含五区块

### 1. 名词映射
- 主角、核心配角、反派、组织/势力、关键地点、关键物品：原书名 → 新书名，逐行列表。
- 新书名要贴合新题材的语感，避免与原书同字同音的可识别词。
- 主角 archetype 不变（如「冷面毒舌女官」），只换姓名与身份包装。

### 2. 金手指映射（功能位等价）
从原书 `设定/世界观/金手指.md` 提取三类规则，逐类给出新书等价物：
- 获取方式：原书怎么得到 → 新书怎么得到。
- 升级方式：原书怎么变强 → 新书怎么变强。
- 使用代价：原书代价是什么 → 新书代价是什么。
三类必须一一对应，缺一则功能位不等价，爽点节奏会变。

### 3. 功能位保留
逐条引用 `剧情/情绪模块.md` 的 EM 卡：
- EM 编号 + 模块名 + 读者想看什么（功能位，保留）。
- 可替换项：该卡列出的可替换要素 → 落到新书的具体名词。
- 不可照搬：该卡列出的不可照搬项 → 新书如何规避。
- 失效情形：提醒 Phase 2 在哪些章节该模块生效。

### 4. 点睛句保留
- 原书标志性句式/吐槽口吻（从 `文风.md` 提取）→ 新书主角等价口吻。
- 参考 `文风.md` 的「不可模仿」节：不照搬可识别素材（具体典故、专有名词、作者梗）。
- 给出 2-3 句示例：原句 → 新句，展示口吻等价。

### 5. 文风指令
从 `文风.md` 提炼 3-5 条可写入细纲 `〖写作要求〗` 的叙事风格句，例如：
- 「对话短句为主，长句不超过25字。」
- 「情绪交替：每3段紧张插1段轻松吐槽。」
- 「场景描写用动作带过，不用形容词堆砌。」
这些指令 Phase 2 会写进每章 `〖写作要求〗` 的「叙事风格」字段。

## 锁定规则

- 映射表落盘后，Phase 2 逐章只按表换名词，不新造、不遗漏。
- 后续阶段发现冲突（某章情节点涉及映射表未覆盖的名词）：回 Phase 1 补表，再重出该章，**不许在细纲里悄悄改**。
- 作者确认方式：展示映射表全文，作者回复「确认」或指出要改的名词。
