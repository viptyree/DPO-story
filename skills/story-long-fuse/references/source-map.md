# Phase 0：多源选源、体检与分工

本 skill 只读拆文库，不拆书。拆文库由 `/story-long-analyze` 产出，目录形如 `{拆文库根}/<对标书名>/`。

## 强制规则

1. **源书 ≥2 本**。只有 1 本可用源书时停，报告 `missing_source`，建议先跑 `/story-long-analyze` 补拆第二本。**不做单源降级**——单源时"跨源拼接"的核心保证失效，相似度会回到 story-long-go 的水平。
2. **分工必须覆盖两个层**：至少一本供**骨架层**（节奏/爽点间隔/钩子类型），至少一本供**设定层**（金手指机制/人设）。第三本可选，供场景/桥段/口吻层。
3. 源书之间**切入点应不同**（如一本废柴流、一本系统流、一本重生流）。两本切入点完全相同（同题材同套路同开局）时提示作者：防举报效果打折，建议换一本切入角度不同的。

## 每本源书的必备文件

| 文件 | 用途 | 缺了影响 |
| --- | --- | --- |
| `章节/第N章_摘要.md`（N=1..范围上限） | 每章 P1..Pn 情节点（类型/基调/涉及/地点/物品/时间） | Phase 1 功能表的唯一依据 |
| `剧情/情绪模块.md` | EM 模块卡（可替换项/不可照搬/失效情形） | Phase 2 功能位保留、Phase 3 跨源拼接 |
| `文风.md` | 语感、对话技法、口吻、不可模仿 | Phase 2 口吻融合 |
| `设定/世界观/金手指.md` | 金手指规则（获取/升级/代价） | 仅**设定源书**必备，供骨架的书可缺 |

骨架源书额外必备：`剧情/节奏.md`（爽点/钩子位置、循环单元）。
可选文件（有则增强）：`章节/第N章_深度拆解.md`、`设定/世界观/力量体系.md`、`角色/角色关系.md`、`角色/<配角>.md`。

> 注意与 story-long-go 的差异：go 要求 `角色/<主角>.md` 必备（名词映射要对主角卡）；fuse 的名词映射以**事件功能表里实际出场的人物**为准，主角卡可降为可选。

## 章节摘要格式约定（同 story-long-go）

每章 `第N章_摘要.md` 必须含 P 情节点清单，每点一行，含：类型、基调、涉及人物、地点、物品、时间。情节点数量逐章不同，以该章实际点数为准。缺 P 情节点的章节 → 报告 `missing_source`，建议对该书补拆。

## 体检流程

1. 接收 2-3 个拆文库路径（运行时传入）；未给全时列出已知拆文库根（如 `D:\劳动仲裁\novel\yaomo\拆文库\`、`D:\劳动仲裁\novel\feilinggen\`）下的候选书目录供选择。
2. 按分工逐本检查必备文件与章节摘要齐全性。
3. 判定分工：向作者确认"哪本供骨架、哪本供设定（、哪本供场景）"，给推荐（节奏/爽点设计更成熟的供骨架，金手指/人设更有辨识度的供设定）。
4. 确认范围：默认前 15 章。**新书章号连续编号**（1..N），不要求与任何一本原书章号一一对应——这是与 go 的另一差异：go 是第 N 章对第 N 章，fuse 的功能表按"新书第 N 章需要哪些功能点"排列，来源章号是自由组合。
5. 产出 `融合/源书分工.md`：

```md
# 源书分工
- 范围：前 {N} 章（新书章号 1..{N}）
- 源书A：{书名}，路径 {path}，供：骨架层（节奏/钩子）
- 源书B：{书名}，路径 {path}，供：设定层（金手指/人设）
- 源书C（可选）：{书名}，路径 {path}，供：场景/口吻层
- 各源书可用章节范围：A=1..{nA}，B=1..{nB}
- 单源上限：任一书机制贡献 ≤50%（按 EM 卡计）
- 体检结果：{完整 / 缺失清单}
```
