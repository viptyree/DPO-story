# Phase 2：分层映射表协议

输出文件：本书目录 `融合/映射表.md`。作者确认并锁定后才进入 Phase 3。

## 目标

把各源书的可识别素材（人名/地名/金手指/句式/口吻）换成新书等价素材，**并显式标注每类机制取自哪本**，让"像哪本"在规划层就可核查。映射表是 Phase 3 名词替换和口吻落地的唯一依据，细纲里不许出现映射表之外的新名词。

## 四层取料分工（对应 SKILL.md 的层模型）

| 层 | 内容 | 来源规则 |
| --- | --- | --- |
| 骨架层 | 爽点间隔、钩子位置、信息差节奏 | 只取**抽象机制**（"每3章一小高潮"），不取具体事件；主要来自骨架源书 `剧情/节奏.md` |
| 事件层 | 具体发生了什么 | 按功能表逐点重做；机制灵感可跨源，但**具体事件必须原创** |
| 设定层 | 金手指、世界观、角色组合 | 必须重做，不能换皮；机制从设定源书借，包装全新 |
| 血肉层 | 场景、对话、细节 | 100% 原创（Phase 3/正文阶段落实） |

## 映射表必含六区块

### 1. 名词映射
- 范围 = 事件功能表里实际出场的人物/地点/物品/势力（以功能表为准，不按主角卡）。
- 原书名 → 新书名逐行列表；主源书（功能点占比最高的那本）的名词必须全量映射，其他源书只映射实际被借机制涉及的名词。
- 新书名贴合新题材语感，避免与原书同字同音的可识别词。
- 主角 archetype 可跨源组合（如 A 书的"隐忍" + B 书的"毒舌"），组合后写一句"这个组合在任何单源书里都不存在"的自证。

### 2. 金手指映射（功能位等价，机制取自设定源书）
从设定源书 `设定/世界观/金手指.md` 提取三类规则，逐类给新书等价物：
- 获取方式：原书怎么得到 → 新书怎么得到
- 升级方式：原书怎么变强 → 新书怎么变强
- 使用代价：原书代价是什么 → 新书代价是什么

三类必须一一对应，缺一则功能位不等价、爽点节奏会变。**包装（名称/形态/外观）必须全新**，只等价规则。若第三本源书有可借的"代价"或"限制"机制，优先用它替换设定源书对应类，进一步拉开单源占比。

### 3. 功能位保留（分源标注）
逐条引用**各源书** `剧情/情绪模块.md` 的 EM 卡：
- EM 编号 + 来源书 + 模块名 + 读者想看什么（功能位，保留）
- 可替换项 → 落到新书具体名词
- 不可照搬项 → 新书如何规避
- 失效情形 → 哪些章节该模块生效
- 末尾统计：各源书 EM 卡贡献数与占比（对照单源上限 ≤50%）

### 4. 口吻融合
- 各源书标志性句式/吐槽口吻（从各自 `文风.md` 提取，各取 ≤3 条）→ 融合成新书主角**统一口吻**
- 参考各源书 `文风.md` 的「不可模仿」节：不照搬可识别素材（具体典故、专有名词、作者梗）
- 给 2-3 句示例：原句A + 原句B（可来自不同源书）→ 融合后的新句，展示口吻是"混合产物"而非任何一本的翻版

### 5. 文风指纹（防 AI 查重层，与源书无关）
来源优先级：
1. 作者记忆（`/story` 作者记忆协议里的个性化规则：口头禅/句式偏好/比喻风格/字数浮动范围）；
2. 记忆缺失 → 向作者要旧作中最满意的 2-3 段，现场提炼成 3-5 条规则。
提炼维度：
- 口头禅/语气词（"靠""嘶""行吧"这类）
- 句式（逗号长句为主？短句砸？对话多叙述少？）
- 比喻风格（生活化还是文学化）
- 每章字数浮动范围（别每章精确 2000 字，要 1800-2300 波动）
这些指令 Phase 3 写进每章 `〖写作要求〗` 的「叙事风格」字段。**注意：这一层只来自作者本人，不来自任何源书**——源书文风指令（各源书 `文风.md` 的可借鉴写法，每条注明来源）可作补充，但作者指纹规则优先，冲突时以作者指纹为准。

### 6. 单源上限核算
- 按区块 3 的 EM 卡统计 + 功能表情节点来源统计，算出各源书机制贡献占比。
- 任一源书 >50% → 回 Phase 1 调功能表来源（从占比高的书挪 2-3 个功能点到其他源书机制），或在本区块注明"作者已接受超配"及原因。

## 锁定规则

- 映射表落盘后 Phase 3 只按表换名词、落口吻，不新造、不遗漏。
- Phase 3 发现冲突（某章情节点涉及映射表未覆盖的名词）：回这里补表再重出该章，**不许在细纲里悄悄改**。
- 作者确认方式：展示全文，作者回复"确认"或指出要改的名词/口吻/占比。
