# Phase 1：跨书事件功能表协议

输出文件：本书目录 `融合/事件功能表.md`。作者确认并锁定后才进入 Phase 2。

## 目标

把"抄哪本书"的问题从**章级/情节点级**降到**功能级**：功能表只记录"新书第 N 章的每个情节点要完成什么读者功能、机制灵感来自哪本"，不记录"原书具体发生了什么"。具体事件在 Phase 3 重做。

## 功能分类（受控词表）

提取情节点功能时只用以下标签（可组合，主标签一个）：

| 标签 | 含义 |
| --- | --- |
| 立威 | 主角展示实力/身份，改变他人评价 |
| 拉仇恨 | 制造反派/对手的不合理压迫，攒读者怒气 |
| 爽点兑现 | 怒气/期待兑现（打脸/翻盘/获认可） |
| 获资源 | 得到关键物品/信息/能力/机缘 |
| 引入角色 | 新重要人物登场并建立关系 |
| 回收伏笔 | 前文埋的线给出部分或全部答案 |
| 危机升级 | 威胁升级，逼主角出手 |
| 信息差 | 读者/角色知道而对方不知道的局面变化 |
| 过渡 | 场景/阶段切换，无强情绪功能 |
| 章尾钩子 | 停在悬念/危机/新信息上 |

词表外的功能先向作者说明再使用，不静默新造标签。

## 提取流程

1. **逐源书提取**：对每本源书范围内（默认 1..15）每章，读 `章节/第N章_摘要.md` 的 P1..Pn，逐点标注：功能标签 + 一句话"原书具体做法"（≤30字，含角色关系如"被大师兄当众羞辱"）+ 涉及 EM 卡编号（查该源书 `剧情/情绪模块.md`）。
2. **骨架书节奏对齐**：从骨架源书 `剧情/节奏.md` 提取爽点/钩子位置规律（每几章一个小高潮、钩子类型序列），作为功能表排布约束。
3. **排布成新书章**：按节奏规律把功能点排进新书第 1..N 章。排布规则：
   - 每章情节点数参考骨架书同位置章节的密度（不锁死）。
   - 同一章的情节点机制来源**必须跨 ≥2 本源书**（这是"没有单一原型"的结构性保证）。
   - 高价值功能点（立威/爽点兑现/回收伏笔）优先取自**设定源书**的机制（人设和金手指驱动的事件更原创）；纯节奏功能（过渡/钩子位置）取自骨架书。
   - **单源上限**：任一本源书对全书情节点机制贡献 ≤50%。
4. **标高重合风险**：扫描排布结果，满足以下任一条的段落标 `⚠高重合`：
   - 连续 3 章以上，某本源书贡献了该段 ≥70% 情节点机制；
   - 某章出现"功能+做法"都与单本源书 1:1 对应的情节点（Phase 3 必须重做该点）。
   每处 `⚠高重合` 附一行处理建议（从哪本换机制 / 怎么重做）。

## 功能表格式

```md
# 跨书事件功能表（前 {N} 章）
范围：新书第 1-{N} 章；源书：A={书名}(骨架)、B={书名}(设定)、C={书名}(可选)
单源上限：≤50%（按情节点机制来源计）

## 第 1 章
- P1 [拉仇恨] 来源:B ch3-P2「原书做法一句话」→ 重做要求：换施压角色关系
- P2 [获资源] 来源:A ch1-P4「…」→ 保留机制，换机缘载体
- …
- 爽点位置：P{X}（对齐骨架书 ch{Y} 的爽点密度位置）
- 章尾钩子类型：{悬念/危机/新信息}（对齐骨架书同位置钩子类型）

## 第 2 章
…

## 高重合风险汇总
1. 第{a}-{b}章：{源书X} 贡献 {p}% → 处理：{建议}
```

## 锁定规则

- 功能表落盘并经作者确认后锁定；Phase 3 只按表做事件重做，不擅自增删功能点或换来源。
- Phase 3 发现某功能点按表做不出合理事件：回这里改该点来源/功能，重跑校验，不在细纲里静默偏离。
- 作者确认方式：分章展示（默认先看 1/3/5 章），作者回复"确认"或指出要调的章/点。
