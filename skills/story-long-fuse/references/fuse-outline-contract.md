# 融合细纲模板（与 dpo-outline-contract.md 格式一致 + 借鉴锚点段）

本模板与 `C:\Users\Tyree\.claude\skills\story-long-write\references\dpo-outline-contract.md` 的四段式逐段一致。唯一新增段 `## 借鉴锚点` 放在 `长篇追踪约束` 之后，是额外工程段；`build_dpo_prompt.py` 只取固定段名，该段不会进写手 Prompt，正文管线零改动。

## 模板

```md
# 第N章：{新书章名}

## 章节控制
- 所属卷：{卷名或「第一卷」}
- 剧情单元：FU-{N}
- 字数目标：{映射表统一值，默认2500}
- 字数口径：visible_chars_v1
- 视角：{第三人称紧贴主角 等}
- 章节目标：{本章要推进的剧情，一句}
- 目标情绪：{本章主导情绪}
- 章尾停笔点：{具体可核的结尾动作/状态，对齐功能表钩子类型}

## 〖人物状态〗
- 主角：{境界、位置、目的、伤势和认知，用新书名词}
- 其他出场人物：{位置、立场、当前行动，用新书名词}

## 〖前情〗
- 当前局势：{开场前局势，用新书名词}
- 必须承接：{上一章遗留、必须推进的事实}

## 〖事件骨架〗
1. {P1：重做后的可执行、可观察动作与因果，新书名词}
2. {P2：…}
3. {P3：…（点数=功能表该章点数，逐章不同）}

## 〖写作要求〗
- 叙事风格：{作者文风指纹规则3-5条（优先）+ 源书可借鉴写法补充（注明来源）}
- 禁止提前释放：{本章不可提前揭示的信息/底牌}
- 结尾：{章尾停笔点的写法要求，对齐功能表钩子类型}

## 长篇追踪约束
- 必须沿用的事实：{跨章不变的事实，用新书名词}
- 允许发生的状态变化：{本章内允许改变的状态}
- 本章禁止变动的设定：{本章不可改的设定/金手指规则}
- 下一章承接的事实：{本章末尾留给下一章的事实}

## 借鉴锚点
- 功能表引用：融合/事件功能表.md 第{N}章（P1..P{M}）
- 逐点对照：
  - P1 [功能标签] 来源:{源书} ch{X}-P{Y}「原书做法一句话」→ 新书「新做法一句话」（因果链差异：{触发/代价/反应 换了什么}）
  - P2 [功能标签] 来源:{源书} …
- 爽点位置：P{K}（对齐骨架书 ch{X} 的爽点密度位置）
- 章尾钩子：{类型}（对齐骨架书同位置类型）
- 单源占比：{本章内各源书情节点机制占比，如 A:50%/B:50%}
- 高重合点重做：{本章是否有⚠高点；有则注明重做幅度，无则写「无」}
- 最像风险与拉开手段：{本章最可能像哪本源书的哪个位置；靠什么事件差异拉开}
- 禁用原书名词：{本章涉及的各源书人名/地名/物品/组织，合并去重}
```

## 格式一致性规则

1. 四段式 `〖人物状态〗〖前情〗〖事件骨架〗〖写作要求〗` 的段名、字段名、字段顺序与 `dpo-outline-contract.md` 逐字一致。
2. `## 章节控制` 的八个字段（所属卷/剧情单元/字数目标/字数口径/视角/章节目标/目标情绪/章尾停笔点）逐字一致。
3. `## 长篇追踪约束` 的四个字段（必须沿用的事实/允许发生的状态变化/本章禁止变动的设定/下一章承接的事实）逐字一致。
4. `## 借鉴锚点` 是唯一新增段，放在最后；写手编译器不读取，校验器额外校验。
5. 四段式正文中只出现新书名词；原书名词只允许出现在 `## 借鉴锚点` 段。
6. 与 story-long-go 的 `## 换皮对照` 的区别：go 记"原书情节点 1:1 对照"，fuse 记"功能来源 + 重做差异"。两段的细纲不混用（一本书用一种）。

## 校验

- 主校验：`node "C:\Users\Tyree\.claude\skills\story-long-write\scripts\check-outline-contract.js" --json --project "{书目录}" --chapter {N}`（DPO 格式，额外 `##` 段被忽略）。
- 融合校验：`node "{本skill根}/scripts/check-fuse-outline.js" --project "{书目录}" --chapter {N}`（借鉴锚点字段齐全、功能表引用点数一致、单源占比 ≤50%、禁用名词未泄漏、高重合点有重做标注）。
